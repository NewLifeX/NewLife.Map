NewLife.Map 統一封裝百度、高德、騰訊、天地圖等主流地圖服務，提供地理編碼、逆地理編碼、路徑規劃與行政區劃能力。

## 安裝

```bash
dotnet add package NewLife.Map
```

## 快速開始

```csharp
var map = new BaiduMap(accessKey);
var location = await map.GetLocationAsync("北京市海淀区");
```

## 核心特性

- 適配主流雲端服務與託管中介軟體
- 涵蓋主流協定與格式版本，相容性強
- 外掛化與可擴充架構，便於二次開發
