# 需求文档 — NewLife.Map 统一地图组件库与企业地图接口平台

> 本文档由代码扫描反推生成（重建模式），2026-08-04
> 标注 ⚠️ 的推断项需人工确认。

## 1. 愿景

**统一地图能力，屏蔽厂商差异。** 面向 .NET 生态提供一套地图组件库（`NewLife.Map`）与配套的企业地图接口平台（`MapApi`），让上层业务以统一接口调用地理编码、逆地理编码、距离计算与坐标转换，不必关心底层接入的是百度、高德、腾讯还是天地图，也无需在应用侧管理各家 Key 与限流策略。

## 2. 背景与系统定位

- **背景**：主流地图厂商（百度/高德/腾讯/天地图）的 WebService 接口在地址解析、坐标系、错误码、限流策略上差异巨大，业务系统直接对接成本高、切换难。
- **定位**：
  - `NewLife.Map`：**基础类库**（NuGet 包），提供统一接口与多厂商适配，可被任意 .NET 项目直接引用。
  - `MapApi`：**企业级聚合平台**（Web API + 魔方后台），对内聚合多厂商、提供标准化地理服务入口，并通过 GeoHash 多级缓存降低厂商调用量，经星尘注册中心对外提供服务发现。
- **目标用户**：需要地图能力的 .NET 业务系统、企业内网地图服务平台维护者。

## 3. 核心目标

| 目标 | 对应模块 | 说明 |
|------|---------|------|
| 统一接口屏蔽厂商差异 | MAP | `IMap` 接口统一地理编码/逆地理/距离/坐标转换 |
| 多厂商适配与可扩展 | MAP | 内置百度/高德/腾讯/天地图/新生命聚合 5 个提供者，工厂注册机制支持扩展 |
| 坐标系互转 | MAP | 内置 WGS84/GCJ02/BD09 离线转换公式，百度在线转换封装 |
| Key 稳定性保障 | MAP | 多 Key 轮询 + 失效自动熔断 + 定时恢复 |
| 标准化地理服务入口 | API | 对外暴露统一 `Geo` / `ReverseGeo` 端点 |
| 聚合降本与缓存 | API | 多厂商按配置轮询，GeoHash 6~9 位四级缓存，减少重复调用 |
| 后台可视化管理 | API | 魔方后台管理地图提供者、地理数据、平台设置 |
| 多语言本地化 | MAP + API | 异常、日志与元数据按当前语言翻译；11 种语言词表全译，英文为源文与兜底 |

## 4. 功能需求

### 4.1 MAP 模块 — 地图组件库（NewLife.Map）

> 类库定位：`NewLife.Map` 类库，多目标框架 net45/net461/netstandard2.0/netstandard2.1，强命名。

| 编码 | 功能 | 需求描述 |
|------|------|---------|
| MAP-1 | 统一地图接口与抽象基类 | 定义 `IMap` 接口（地理编码/逆地理/距离/坐标转换/日志）与 `Map` 抽象基类（HTTP 调用、密钥管理、错误处理公共逻辑） |
| MAP-2 | 地图工厂与提供者注册 | `MapFactory` 按 `MapKinds` 注册/创建提供者；`Map.Create(名称)` 支持按名称或 `*Map` 后缀自动匹配 |
| MAP-3 | 百度地图提供者 | 地理编码、逆地理编码、驾车距离、POI 检索、IP 定位、在线坐标转换（含 wgs84ll/gcj02ll/bd09ll 等索引映射） |
| MAP-4 | 高德地图提供者 | 地理编码（含地址格式化）、逆地理编码（含乡镇编码解析）、距离计算（直线/驾车/公交/步行） |
| MAP-5 | 腾讯地图提供者 | 地理编码、逆地理编码（含推荐地址）、距离计算（驾车/步行/骑行）、IP 定位；专属失效词识别（TOO_FREQUENT 等） |
| MAP-6 | 天地图提供者 | 地理编码、逆地理编码、距离计算（支持途经点）、POI 检索 |
| MAP-7 | 新生命地图聚合提供者 | 对接 MapApi 平台 `/Map/ReverseGeo`（逆地理）、`/Map/GeoAddress`（正向地理）、`/Map/Distance`（距离）；支持指定服务端地址，或经星尘注册中心自动发现服务端多实例 |
| MAP-8 | 坐标系离线转换 | `MapHelper` 提供 WGS84↔GCJ02↔BD09 公式互转与坐标字符串解析，不依赖网络 |
| MAP-9 | 多Key轮询与自动熔断 | 逗号分隔多 Key 轮询使用；命中失效特征（INVALID/LIMIT/TOO_FREQUENT 等）自动下线该 Key，定时恢复；支持 `ThrowException` 开关 |
| MAP-10 | 数据模型 | `GeoAddress`（地址组件+精度指标）、`Driving`（距离/耗时）、`GeoModel`（平台标准返回）、`GeoArea`（行政区划）、`MapKinds`（厂商枚举） |
| MAP-11 | OSM/Nominatim 地图提供者 | 新增开源免费海外数据源提供者：正向地理编码（search）/ 逆地理编码（reverse），无需 Key，覆盖海外与开源数据场景；扩展 `MapKinds` 枚举并注册 `MapFactory`（竞品遴选，2026-08-04） |
| MAP-12 | 并发限速（令牌桶） | Map 基类可选令牌桶限速，避免单个 Key 因高频请求被整体封禁；`MaxQps` 默认 0 不限速（Roadmap 激活，2026-08-04） |
| MAP-13 | 故障统计 / Metrics | Map 基类内置请求统计：总次数、成功率、平均耗时、Key 命中率（Roadmap 激活，2026-08-04） |
| MAP-14 | Benchmark 基准对比 | BenchmarkDotNet 基准测试项目，覆盖批量坐标转换，输出数据驱动性能报告（Roadmap 激活，2026-08-04） |
| MAP-15 | 运行时多语言 | 英文为源文与兜底，内置 11 种语言词表（zh-Hans/zh-Hant/es/de/ja/fr/pt/ru/ko/ar，键全部有译文）；异常消息、日志、程序集标题与描述、提供者 DisplayName 按当前语言翻译；`Localization.Culture` / `LogCulture` 可固定语言，缺译文回退英文（2026-10-19 新增，2026-10-22 完善） |

### 4.2 API 模块 — 企业地图接口平台（MapApi）

> 平台定位：`MapApi` Web 项目（net10.0），集成魔方（Cube）后台与星尘。

| 编码 | 功能 | 需求描述 |
|------|------|---------|
| API-1 | 平台启动与配置 | 程序启动装配星尘、魔方、XCode 实体初始化；以 `NewLife.Map` 服务名注册到星尘注册中心；SQLite 数据源（`Location` 连接串） |
| API-2a | 地图配置模型 | 平台级配置：启用开关、默认提供者、JsKey/ServiceKey、中心城市、缩放、卫星图、缓存天数；DisplayName/Description 为英文源文并提供 11 种语言译文 |
| API-2b | 地图设置管理页面 | 魔方后台对地图配置的可视化增删改查 |
| API-3a | 地图提供者数据访问 | `MapProvider` 实体管理上游厂商（名称/类型/启用/服务地址/多 Key）；首连数据库时按工厂注册表自动初始化默认提供者 |
| API-3b | 地图提供者管理页面 | 魔方后台维护各厂商 AppKey/服务地址/启用状态 |
| API-4a | 地理数据多级缓存访问 | `Geo6/7/8/9` 四级 GeoHash 精度表（610m/76m/19m/2m），按 wgs84/bd09/gcj02 三套坐标分别建 Hash 索引；`Upsert` 幂等写入，超期刷新 |
| API-4b | 地理数据管理页面 | 魔方后台查询/维护地理缓存数据（支持按区划编码搜索） |
| API-5 | 逆地理编码服务 | `MapService.GetAddress`：内存缓存 → 数据库四级查询 → 未命中调厂商逆地理 → 坐标系转换 → 四级 Upsert 回写 → 回填内存缓存 |
| API-6 | 对外地理服务接口 | `[ApiController]` 暴露 `GET /Map/Geo` 与 `GET /Map/ReverseGeo`（lng/lat/coordtype），匿名访问，统一返回 `GeoModel` |
| API-7 | 在线 IP 解析接口 | 引入 `NewLife.IP` 离线 IP 库，提供 `GET /Map/Ip` 在线 IP 解析接口服务（IP → 物理地址），内网可用不依赖厂商（2026-08-04 新增） |

## 6. 不做什么

- 不做前端地图展示组件（如地图 JS SDK 封装、瓦片加载），本项目仅提供后端服务能力与厂商适配。
- 不做地理围栏、轨迹、导航路线绘制等业务级能力。
- 不维护行政区划数据本身（行政区划由 `Area` 实体导入，属 XCode 基础能力）。
- 不做 Google 系地图适配（竞品 GoogleApi 领域）：服务条款限制 + 愿景聚焦中国厂商（竞品遴选，2026-08-04）。
- 不做通用 GIS 投影（EPSG，竞品 ProjNET 领域）：愿景不含，与 GCJ02/BD09 体系平行（竞品遴选，2026-08-04）。
- 不做 MaxMind 离线 IP 定位库适配：团队已有 `NewLife.IP` 离线库，经 MapApi 平台化提供在线 IP 解析（2026-08-04）。
