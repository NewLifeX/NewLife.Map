# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 11 种语言｜英文为源文与兜底

## 1. 语言分层

本库按 NuGet 下载量分层维护运行时词表：下载量较高的核心组件对齐 NewLife.Core 的 31 种语言，其余组件维护 11 种语言（与 README 读者一致）。缺失译文在运行时自动回退英文，新增语言不需要改代码。

词表文件（10 个，另有英文源文兜底）：

- zh-Hans
- zh-Hant
- es
- de
- ja
- fr
- pt
- ru
- ko
- ar

## 2. 词表文件

- `MapApi/Locales`
- `NewLife.Map/Locales`

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。
- 覆盖范围：异常消息、日志、控制台输出与接口返回的错误消息；`[Description]` / `[DisplayName]` 等元数据不纳入。

### 2.1 运行时语言选择

```csharp
// 固定异常与接口消息语言；null 表示跟随当前 UI 文化
Localization.Culture = new CultureInfo("zh-Hans");

// 请求语言随上下文变化时，可单独固定日志语言
Localization.LogCulture = new CultureInfo("en-US");
```

MapApi 可在 `appsettings.json` 中配置，留空表示跟随操作系统：

```json
"Localization": {
  "Culture": "",
  "LogCulture": ""
}
```

MapApi 还会按请求头 `Accept-Language` 的 q 权重切换本次请求的界面语言，只修改 `CurrentUICulture`，不影响数字与日期格式；`Localization:Culture` 配置后固定语言，请求头不再生效。日志默认固定为宿主语言，避免随请求抖动。

```text
GET /Map/Ip?ip=
Accept-Language: zh-TW       → IP 為空
Accept-Language: fr-CA       → L'IP est vide.
Accept-Language: sw-KE       → 退守宿主语言
```

> 请求语言作用域直接使用 NewLife.Core 的 `NewLife.RequestCultureScope`，Map 不再本地维护实现。

### 2.2 带前缀日志

实例前缀（如 `[Baidu]`）必须**先翻译消息、再拼接前缀**。`Map` 的日志封装已经内置该规则：

```csharp
map.LogPrefix = "[Baidu]";          // 默认使用提供者类型名，如 [Baidu]
map.WriteLog("No available key.");  // 输出 [Baidu]没有可用密钥
map.WriteError("No available key.");// 错误级别，同样先翻译后拼接
```

不要对 `prefix + format` 整串调用 `L.T`，也不要直接交给 `Logger.Format` 查表——前缀随实例变化，整串永远匹配不到词条。自定义日志封装应使用 `Log.InfoPrefixed` / `Log.ErrorPrefixed` / `Log.WritePrefixed`。

## 3. 新增一条消息

1. 代码中写英文源文：`throw new XException("Session {0} is closed.", sessionId);`；BCL 异常用 `L.T("English template", args)`；日志直接写英文模板（`Logger.Format` 自动翻译），带实例前缀时使用 `Log.InfoPrefixed` / `Log.ErrorPrefixed`。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

> 日志必须使用**格式字符串 + 参数**，不要使用字符串插值（`$"..."`）；插值后模板已展开，无法再按原文查表。

## 4. 校验

```powershell
pwsh -File tools\check-locales.ps1 -LocaleDir NewLife.Map/Locales -SourceDir NewLife.Map
pwsh -File tools\check-locales.ps1 -LocaleDir MapApi/Locales -SourceDir MapApi
```

CI 的 localization job 会执行同一脚本。
